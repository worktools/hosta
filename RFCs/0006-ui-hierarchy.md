# RFC 0006：界面层级设计与信息架构

- 状态：Proposed
- 日期：2026-08-10

## 1. 目的

定义 Hosta 的界面层级、导航结构和页面组件树，确保用户能直观地管理程序的全生命周期。参考 Vercel Dashboard 的信息架构，但针对"小程序管理"场景进行简化。

## 2. 信息架构

```text
Workspace（工作区）
├── 程序列表（/apps）
│   └── 每个程序卡片：名称、描述、运行时、状态（LIVE/DRAFT）、运行次数
│
├── 新建程序（/new）
│   └── 表单：名称、描述、运行时选择、示例输入
│
└── 程序详情（/apps/:code）
    ├── 代码编辑器（主工作区）
    │   ├── 代码编辑区
    │   ├── 请求/输入区
    │   └── 结果/输出区
    │
    ├── 测试用例
    │   ├── 测试列表
    │   ├── 添加测试
    │   ├── LLM 生成测试
    │   └── 批量运行结果
    │
    ├── 数据源
    │   ├── 数据编辑器
    │   ├── 迁移脚本
    │   ├── 迁移结果（待确认提示）
    │   └── 历史快照（含待确认/已应用状态）
    │
    ├── 版本管理
    │   ├── 版本列表
    │   ├── 版本状态（draft / ready / published）
    │   ├── 设为默认版本
    │   └── 版本对比（后续）
    │
    └── 调用文档
        ├── 调用地址
        ├── 认证方式
        ├── 示例输入
        ├── curl 示例
        └── 密钥管理（仅显示一次）
```

## 3. 页面层级树

```text
<App>
├── <Sidebar>                       // 左侧导航
│   ├── Brand (Hosta logo)
│   ├── Nav items (程序 / 新建程序)
│   ├── LLM Agent 指南链接
│   └── Recent apps list
│
├── <Header>                        // 顶部栏
│   ├── Breadcrumb
│   ├── Page title
│   ├── Runtime badge
│   └── Refresh button
│
├── <Notice />                      // 全局通知条
│
├── <AppList />                     // 列表视图
│   └── <AppCard /> × N
│
├── <Create />                      // 创建视图
│   └── Form fields
│
└── <Editor />                      // 编辑视图
    ├── <EditorHead>                // 编辑器顶部操作栏
    │   ├── Version status badge
    │   ├── Version info
    │   ├── Delete / Format / Save / Publish buttons
    │   └── Runtime & language info
    │
    ├── <TabBar />                  // 标签页导航
    │
    ├── <CodePanel />               // Tab 1: 代码
    │   ├── Code editor (textarea)
    │   ├── Request input (textarea)
    │   ├── Run / Diagnose buttons
    │   └── Result output (pre)
    │
    ├── <TestPanel />               // Tab 2: 测试
    │   ├── Test list
    │   ├── Test add form
    │   ├── Generate tests button (LLM)
    │   ├── Run all button
    │   └── Test results
    │
    ├── <DatasourcePanel />         // Tab 3: 数据源
    │   ├── Data editor (textarea)
    │   ├── Save button
    │   ├── Migration script editor
    │   ├── Run migration button
    │   ├── Migration result (with pending hint)
    │   └── Snapshot list (with promote/restore)
    │
    ├── <VersionPanel />            // Tab 4: 版本
    │   └── Version items
    │       ├── Version number
    │       ├── Status badge
    │       ├── Tags (draft / live)
    │       ├── Source & date
    │       └── Set as default button
    │
    └── <DocsPanel />               // Tab 5: 调用文档
        ├── Invoke URL
        ├── Slug editor
        ├── Deployment info
        ├── GET / POST examples
        ├── curl snippet
        └── Key display
```

## 4. 状态展示规范

### 4.1 程序列表卡片

```
┌──────────────────────────────┐
│ [JS]  LIVE                   │
│ 订单汇总                      │
│ 按币种汇总有效订单金额         │
│ ──────────────────────────── │
│ 6-order-summary    12 runs   │
└──────────────────────────────┘
```

- 运行时标签：`[JS]` / `[WASM]` / `[WASM/Rust]` / `[WASM/MoonBit]`
- 状态标签：`LIVE`（绿色） / `DRAFT`（灰色）
- 底部：程序编码 + 运行次数

### 4.2 版本列表

```
┌──────────────────────────────────────────────────────┐
│ v3  ready  [当前编辑]  [默认版本]                       │
│ manual-edit  2026-08-10 10:30  修复了精度问题          │
│                                          [设为默认版本] │
├──────────────────────────────────────────────────────┤
│ v2  ready                                              │
│ deepseek  2026-08-10 09:00  按币种汇总，支持多币种     │
│                                          [设为默认版本] │
├──────────────────────────────────────────────────────┤
│ v1  needs_revision                                     │
│ deepseek  2026-08-10 08:00  初始生成                   │
│                          需要诊断通过后才能设为默认版本  │
└──────────────────────────────────────────────────────┘
```

### 4.3 数据源快照

```
┌──────────────────────────────────────────┐
│ 2026-08-10 10:30 · 待确认                 │
│ [✅ 应用] [恢复]                          │
│ ┌──────────────────────────────────────┐ │
│ │ {"users": [...], "version": 2, ...}  │ │
│ └──────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

- 待确认快照：橙色边框 + 橙色背景
- 已应用快照：正常样式 + "已应用"标签
- 普通快照：正常样式

## 5. 空状态设计

### 5.1 程序列表为空

```
┌─────────────────────────────────────┐
│                                     │
│        还没有程序                     │
│   描述你的第一个自动化需求             │
│                                     │
│        [创建第一个程序]               │
│                                     │
└─────────────────────────────────────┘
```

### 5.2 测试用例为空

```
暂无测试用例。至少需要 3 组测试数据来验证功能。
在下方添加测试输入，或使用 "✨ 生成测试" 让 LLM 自动生成。
```

### 5.3 数据源为空

```
暂无快照。保存数据或执行迁移时自动创建。
```

### 5.4 版本列表为空

```
暂无版本。请先在代码编辑器中"编译并保存"。
```

## 6. 响应式与交互

### 6.1 加载状态

- 生成中：按钮显示"生成中…"，禁用
- 运行中：按钮显示"运行中…"，禁用
- 编译中：按钮显示"编译中…"，禁用
- 数据加载：内联 loading 提示

### 6.2 错误状态

- 网络错误：全局 notice 红色提示条
- 校验错误：内联红色错误信息
- 运行错误：结果区显示错误详情
- 模型错误：明确提示是模型调用失败

### 6.3 确认操作

- 删除程序：`confirm()` 对话框
- 恢复快照：`confirm()` 对话框
- 应用迁移：`confirm()` 对话框
- 发布：直接执行（可撤销，切换版本即可回滚）
